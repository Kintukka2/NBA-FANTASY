# Offseason Impact Report — every roster change since June 2026

League **423671879** · compiled **8 Oct 2026**, draft night · sources: NBA.com transaction tracker, ESPN depth charts and injury report, Spotrac contract data, Basketball Reference 2025-26, Hoops Rumors, team beat reporting.

This document exists to answer one question for every player in the pool: **does last season's number still describe this season's situation?** Our scoring is custom, so the answer is often different from what a standard-scoring ADP implies.

Scoring reference throughout:

```
FPTS = PTS + 2·FGM − FGA + FTM − FTA + 3PM + REB + OREB + 2·AST + 4·STL + 4·BLK − 2·TO
       + 3·DD + 6·TD + 40·QD
```

Net per event: **made two +3 · made three +5 · missed FG −1 · STL +4 · BLK +4 · AST +2 · DREB +1 · OREB +2 · TO −2.**

### A second structural hole, found while rebuilding the pipeline

ESPN's per-game average **amortises the double- and triple-double
bonuses into the rate**: `A_FPTS_AVG` is exactly `A_FPTS / A_GP`, and the
season total already contains them. Recomputing from the bare per-game
formula therefore lands **5.68 pts/game low on Jokić** (55 DD + 34 TD
over 65 games), 3.13 low on Jalen Johnson, and 2.06 low on both
Wembanyama and Cade Cunningham. It understates exactly the archetype
this scoring rewards. `recompute.py` now emits `FP_ACT_PG_CORE` and
`FP_ACT_BONUS_PG` separately so the bonus is visible rather than
assumed.

(27) and Moody (12). But **Brandon Ingram is projected for 67 games
while listed `OUT`**. ESPN's own model is stale on the single name the
market is most wrong about: ADP 79.9, **81.6% rostered**.
